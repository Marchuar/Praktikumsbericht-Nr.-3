# Praktikumsbericht Nr. 3

Webseite für den dritten Praktikumsbericht am Robert-Bosch-Berufskolleg. Die Webseite habe ich allein entwickelt, für den Bericht, den Bohdan und ich gemeinsam abgegeben haben. Für Animationen und Effekte habe ich fertige Komponenten aus verschiedenen Bibliotheken kombiniert und mit Claude zusammengebaut.

**Live-Demo:** https://praktikumsbericht-nr-3.vercel.app

## Technik
React, TypeScript, Vite, Tailwind CSS, React Router, Framer Motion, tsParticles

## Starten
```bash
yarn install
yarn dev
```
